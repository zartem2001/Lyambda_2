# Задача : Работяга — собственный функциональный интерфейс

## 📋 Описание задачи

Реализовать класс `Worker`, который выполняет 100 задач и возвращает результат 
в родительский класс `Main` через собственный функциональный интерфейс 
`OnTaskDoneListener`.

## 🎯 Цель

Освоить создание собственных функциональных интерфейсов, работу с callback-механизмом 
и лямбда-выражениями в Java.

## 🛠️ Используемые технологии

- Java 17+
- Собственный функциональный интерфейс (`@FunctionalInterface`)
- Лямбда-выражения
- Ссылки на методы (`System.out::println`)
- Callback-механизм
